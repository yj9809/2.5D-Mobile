# Compact Factory 0단계 플레이 테스트

씬: `Assets/2. Scene/CompactFactory_Playtest.unity`

기존 `Game.unity`의 플레이어, UI, 생산 및 판매 오브젝트를 복사해
`CompactFactory_Layout.unity`의 0단계 배치와 결합한 임시 테스트 씬이다.
기존 `Game.unity`는 수정하지 않고, 컴팩트 레이아웃과 테스트 씬을 함께 관리한다.

## 실행

1. Unity에서 `Tools > Churub > Compact Factory > Use Stage 0 Playtest In Editor` 선택.
2. `Title.unity`를 열고 Play 실행. 타이틀의 기존 로그인과 데이터 로딩을 거쳐 테스트 씬에 진입한다.
3. 원래 씬으로 돌아가려면 `Use Original Game In Editor` 선택.

확인 순서: 컨테이너 벨트에서 연어가 수령판까지 이동하는 것을 본 뒤 수령하고,
가공대 오른쪽 발판에서 연어를 투입한다. 가운데 발판에 서서 가공한 뒤
왼쪽 작업대의 완제품을 수거해 앞벽 판매대 안쪽으로 운반한다.
진열 후 보도를 지나던 NPC가 재고를 확인하고 상품을
한 개 구매한다. 구매 즉시 플레이어 골드가 증가한다.

테스트 씬을 처음부터 다시 만들 때는 현재 테스트 씬의 편집 내용을 보존한 뒤
`CompactFactory_Playtest.unity`와 메타 파일을 제거하고
`Build Stage 0 Playtest` 메뉴를 실행한다.
`Validate Stage 0 Playtest` 메뉴로 트리거, 액션 참조 및 누락 스크립트를 재검사할 수 있다.

## 연결한 동선

| 위치 | 연결된 기존 기능 |
| --- | --- |
| 컨테이너 앞 (-3.5, 2) | 컨테이너 안쪽까지 이어진 벨트에서 실제 연어 프리팹 수령 |
| 가공대 앞 오른쪽 (1.18, 1.1) | 오른쪽 원료 트레이에 연어를 최대 100개 투입 |
| 가공대 앞 가운데 (0, 1.1) | 플레이어가 서 있는 동안 연어를 약 2.5초마다 완제품으로 가공 |
| 가공대 앞 왼쪽 (-1.18, 1.1) | 트레이 없는 왼쪽 작업대에 완제품을 최대 100개 모아 수거 |
| 판매대 안쪽 (1.4, -3.75) | 츄르를 앞벽 진열대의 여섯 칸에 배치 |
| 판매대 바깥 보도 (1.4, -6.6) | NPC가 재고가 있을 때 한 개 구매하고 골드 즉시 지급 |

원래 컨베이어와 설비는 이 테스트 씬에서 비활성화했다. 컨테이너 공급 벨트는 길이 3.2m로
컨테이너 안쪽까지 연장했고, 연어는 벨트 상단에서 생성되어 일정 속도로 끝까지 이동한 뒤
은색 수령판에 놓인다. 수령판은 한 층에 3개씩 최대 50개를 쌓으며 이 재고도 저장 및 복원된다.
새 가공대는
기존 `Item`, `ItemBuffer`, 플레이어 운반 인벤토리 및 풀링을 사용한다.
진열 상품은 NPC 한 명이 방문할 때마다 최대 1개씩 판매된다. 재고가 없으면
NPC는 그대로 지나가며, 판매 수익은 기존 골드 UI에 즉시 반영된다.
가공대 완제품이 100개 차면 수거할 때까지 가공을 기다린다. 판매대는 한 줄 여섯 칸에
완제품을 진열하며, 각 칸의 아이템은 판매될 때 한 개씩 제거된다.
가공대 앞 주황 발판 세 개는 오른쪽 원료 투입, 가운데 수동 가공, 왼쪽 완제품 수거에 맞춘다.
투입만으로는 가공이 시작되지 않으며 가운데 발판을 떠나면 가공 시간이 일시 정지된다.
가공 중에는 기존 플레이어 포장 애니메이션이 재생되고 머리 위 츄르 제품 아이콘을 둘러싼
원형 UI가 0부터 1까지 찬다.
완료 시 완제품이 놓이며 다음 재료의 진행률은 다시 0부터 시작한다. 가공이 멈추거나
원료가 없을 때는 애니메이션과 UI를 숨긴다. 완제품은 한 층에 6개씩, 최대 100개까지
위층으로 쌓인다.
고객 보도의 `NavMeshSurface`는 플레이테스트 시작 시 보도 메시만 수집해 경로를 만든다.
NPC는 `NavMeshAgent`로 입구에서 판매대 앞을 거쳐 출구로 이동한다.
NPC 생성 간격과 보행 속도, 보도 내 이동선은 매번 달라지고 양방향으로 오간다. 일부는
판매대에 멈추지 않고 지나가며, 재고가 있을 때 약 절반만 구매를 시도한다. 최대 7명이
동시에 보행하고 간헐적으로 두 명이 짧은 간격으로 등장한다.
입구·판매대·출구 사이에 완전한 경로가 없으면 고객 생성을 중단하고 오류를 기록한다.
기존 판매 수익 수령 UI는 테스트 씬에서 비활성화된다.
공급판 재고, 가공대의 투입·완제품, 진열 재고, 플레이어가 운반 중인 재료·제품은
기존 자동 저장과 종료 시 로컬 스냅샷에 포함되며 재진입 시 복원된다.
가공 중 저장한 재료는 재진입 후 가운데 발판에 다시 올라가면 가공 시간을 처음부터 진행한다.
가이드와 직원 생성은 비활성화했고, 추가 설비와 확장 진행은 새 배치에 연결하지 않았다.
타이틀 진입에는 기존 계정 및 서버 초기화가 필요하며, 에디터 외 빌드에서는
계속 원래 `Game` 씬을 로드한다.
