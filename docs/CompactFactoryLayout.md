# 소형 공장과 최종 확장 배치

씬: `Assets/2. Scene/CompactFactory_Layout.unity`

실제 Unity 메시를 배치한 **공간 검토 씬**이다. `Game.unity`, 빌드 씬 목록, 경제·생산·저장 로직에는 적용하지 않는다. 이동 가능한 플레이 버전이 아니며 주황 마커는 위치 표시다.

## 성장 단계

| 단계 | 제조 설비 | 공간 변화 |
|---|---|---|
| 0 | 수동 가공대 1개 | 실내 10 × 10m, 왼쪽 뒤 컨테이너, 앞벽 외부 판매대 |
| 1 | 자동 설비 1개 | 수동 가공대 자리를 첫 기계로 교체, 실내 크기는 유지 |
| 2 | 자동 설비 2개 | 오른쪽 6 × 10m 생산 구역과 오른쪽 뒤 12 × 8m 포장·납품 구역 개방 |
| 3 | 자동 설비 3개 | 오른쪽 두 번째 6 × 10m 구역까지 개방 |

컨테이너 1개, 판매대 1곳, 별도 포장대 1개, 트럭 납품 구역 1곳을 유지한다. 단계는 배치 확인용이며 실제 구매 순서나 비용은 구현하지 않았다.

## 고정 동선

- 컨테이너 몸체: 기존 모델/배율 그대로 중심 (-3.5, 0, 7.35). 실내 뒤쪽 z=5 경계 밖.
- 공급 벨트 길이 1.8m. 은색 판은 (-3.5, 0.02, 3.29)의 바닥에 붙여 벨트 끝 앞에 둔다. 수령 마커는 (-3.5, 0.02, 2.0).
- 수동/첫 자동 가공 위치는 (0, 0, 2.4). 추가 설비 중심은 (8, 0, 2.4), (14, 0, 2.4).
- 첫 자동 설비는 13m 컨베이어 라인 전체가 아니라 기존 가공 본체 메시를 재사용한 소형 배치안이다. 입력·출력 장치와 제조 애니메이션은 후속 구현 대상이다.
- 판매대는 남쪽 벽의 개구부, 중심 (1.4, 0, -5.45). 진열은 실내, 구매·대기는 실외 보도에서 이루어질 자리다.
- 고객 보도는 z=-7.5 ~ -5, 전면 도로는 z=-13.5 ~ -7.5. 직원 입구 x=-3 ~ -0.4 유지.
- 포장대 중심은 (7.5, 0, 8.5), 트럭 중심은 (14, 0, 10). 후방 하역장과 동쪽 서비스 도로로 연결한다.
- 과거 남쪽 포장·출하 구역은 제거했다. 앞쪽은 고객 공간으로 유지한다.

## 주변 배경

기존 Game 씬의 주택·상점·나무·가로등 모델을 재사용한다. 도로와 부지 바닥은 단순 메시다. `Permanent Background` 그룹은 네 단계에서 이동하지 않는다.

최종 확장 구역 x=5 ~ 17, z=-5 ~ 13에는 영구 배경 건물/나무를 넣지 않는다. 초반에는 울타리로 막힌 부지로 표시한다. 해금 단계에서는 임시 부지/울타리 대신 작업장 바닥·설비를 표시한다. 트럭 도로는 동쪽에서 뒤쪽으로 접근하도록 공간을 확보했다. 실제 차량 경로와 NavMesh는 아직 없다.

## Unity에서 확인

씬을 연 뒤 `Tools > Churub > Compact Factory` 메뉴:

- `Stage 0 - Manual Shop`
- `Stage 1 - First Automation`
- `Stage 2 - Second Line and Dispatch`
- `Stage 3 - Three Lines`

기존 `Show Starter Layout`, `Show Expanded Layout`은 각각 0/3단계로 연결된다. 메뉴는 오브젝트 활성 상태와 카메라를 변경한다. 저장하면 선택한 단계가 저장되며 기본 전달 상태는 0단계다.

이미지: `docs/previews/CompactFactory_Starter.png`, `CompactFactory_Automation.png`, `CompactFactory_TwoLines.png`, `CompactFactory_Expanded.png`, `CompactFactory_Masterplan.png`.

## 파일 및 검증

- `Assets/Editor/FactoryGrowthLayout.cs`: 확장 그룹·배경·단계 전환·렌더·배치 검증.
- `Assets/Editor/CompactFactoryLayout.cs`: 기존 초반 배치 도구. 단계/렌더 호출은 최종 배치 도구로 전달한다.
- `Assets/Art/CompactFactoryLayout`: 바닥·도로·외곽용 재질.
- `Logs/CompactFactory/growth-validation.txt`: 단계별 설비 수, 수동/자동 교체, 누락 메시/재질/스크립트, 배경 부지 침범 검사.
- 생성 시 원본 Game 씬의 SHA-256을 전후 비교해 보존 여부를 확인한다.

미구현: 판매·가공 로직, 고객 스폰, 명성, 해금 가격, 튜토리얼, 저장 호환성, NavMesh, 차량 주행, 애니메이션 연결. 기존 포장대 상판 약 0.47m와 새 가공대 상판 1.09m 사이의 손 애니메이션 정합도 후속 확인이 필요하다.

Growth Review: 확장 부지와 영구 배경을 분리하고 적용 범위를 배치 씬으로 명시한다. 은색 수령판은 벨트 끝 앞 바닥에 둔다는 사용자 결정을 이 문서에 기록했다. 전역 파일은 변경하지 않았다.
